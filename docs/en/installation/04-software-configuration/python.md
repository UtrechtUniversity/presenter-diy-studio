## Python

- First check the exact Python version required in [the GitHub repository's README](https://github.com/UtrechtUniversity/diy-studio-app).

- Sign in as **User**, not **Setup**.

- Open **Microsoft Store**. This is only possible while the Windows user interface is still enabled.

- Install **Python Install Manager**.

- Open Command Prompt by pressing the Windows key, typing `cmd` and pressing Enter. Install Python using the following command, replacing the version number with the one you found in the first step:

    ```
    pymanager install 3.14.7
    ```

- If prompted to set `LongPathsEnabled` to `1`, accept and confirm with the administrator password.
