## Python

- Controleer eerst welke Pythonversie je exact moet installeren [in de readme van de GitHub-repository](https://github.com/UtrechtUniversity/diy-studio-app)

- Log in als **User** (niet **Setup**).

- Open de **Microsoft Store** (dit kan alleen als de Windows gebruikersinterface nog is ingeschakeld).

- Installeer **Python Install Manager**.

- Open een command prompt (Windows-toets, typ `cmd`, druk op enter) en installeer Python als volgt, waarbij je het versienummer invult dat je in de eerste stap hebt opgezocht:

    ```
    pymanager install 3.14.7
    ```

- Als er gevraagd wordt om `LongPathsEnabled` op `1` te zetten, doe dit dan en bevestig met het administratorwachtwoord.
